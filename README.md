# ⚡ PySpark Learning Journey

> **From Zero → Job-Ready Data Analyst with PySpark**

A hands-on daily learning journey focused on **Apache Spark, PySpark, DataFrames, SQL, performance optimization, and real-world data pipelines**.

The goal is simple: **learn → practice → build → document → become job-ready.** 🚀

---

## 🎯 Learning Goals

* 🐍 Learn PySpark from the fundamentals
* 📊 Work with large datasets using Spark DataFrames
* 🔗 Master joins, window functions, and Spark SQL
* 📁 Understand Parquet and partitioned data
* ⚡ Learn Spark performance optimization
* 🧠 Understand lazy evaluation and query execution
* 🏗️ Build real-world data pipelines
* 💼 Prepare PySpark skills for **Data Analyst / Data Engineer roles**

## 🚀 Setup & Installation

### 1️⃣ Install PySpark

```bash

```

### 2️⃣ Clone the Repository

```bash

```

### 3️⃣ Open the Project

```bash
cd pyspark-learning-journey
```

### 4️⃣ Run an Example

```bash
python day-01-intro-and-architecture/example.py
```
